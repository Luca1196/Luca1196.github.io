# Inducción y recursión

Teórico de Lógica · inducción (conjuntos inductivos, funciones recursivas, pruebas por inducción).

## Lo esencial
<!-- re: inductiv|recursi|inducción|PIP|HI|TI|cláusula -->

Conjunto inductivo: cláusulas base (quién está de entrada) y cláusulas inductivas (cómo se arma un elemento nuevo con otros).

Función por recursión: un caso por cláusula;
en la inductiva se llama a sí misma sobre las partes.

Prueba por inducción (PIP): un paso base por cada cláusula base, probado solo con definiciones;
y un paso inductivo por cada cláusula inductiva, donde se supone la propiedad para las partes (HI) y se prueba para el elemento nuevo (TI).

En una cadena, cada paso se justifica con una definición, una propiedad dada o la HI.
